# ไฟล์อ้างอิง

- `RCTankC.exe`: ไฟล์ผู้ใช้แนบ ใช้อ้างอิงเท่านั้น **ห้ามรัน แกะโค้ด หรือ disassemble**
- `geometry-example.json`: โจทย์คำนวณมือที่สร้างเพื่อทดสอบเรขาคณิต ไม่ใช่ผลจาก RCTankC

ยังไม่มีเอกสารหรือคู่ข้อมูลเข้า → ผลลัพธ์ของ RCTankC

ไฟล์ `.exe` เก็บเฉพาะใน workspace และไม่รวมใน Git/แพ็กเว็บ เพราะไม่จำเป็นต่อ build หรือการทดสอบ รายละเอียดขนาดและ checksum อยู่ใน `docs/reference-analysis.md`
