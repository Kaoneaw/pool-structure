# ผลตรวจเครือข่ายหลังบันทึกการตั้งค่า

ตรวจซ้ำวันที่ 20 ตุลาคม 2026 (Asia/Bangkok) หลังผู้ใช้สั่งทำต่อ

## หลักฐานล่าสุด

- อ่านการตั้งค่าจากเครื่องมือสำเร็จ: ไม่มี draft ค้าง (`draft_id: null`) และมี base version แล้ว
- รายการ custom domains มีครบทั้ง 7 โดเมนที่เคยขอ ไม่มี secret หรือค่าตัวแปรที่ยังรอกรอก
- เครื่องปัจจุบันใช้ proxy ที่แพลตฟอร์มเตรียมไว้ ไม่แก้ proxy, certificate หรือปิด TLS verification
- คำขอ HTTPS ไป `www.concrete.org`, `www.dpt.go.th`, `ratchakitcha.soc.go.th`, `eit.or.th` และ `technical.buildingsmart.org` ได้ `CONNECT tunnel failed: 403 Forbidden`
- ทดสอบคำขอ HEAD แบบอ่านอย่างเดียวไป ACI นอก shell sandbox โดยใช้เส้นทางเดิมแล้ว ยังได้ 403 จาก `envoy` เช่นเดิม จึงไม่ใช่แค่ผลของ filesystem/shell sandbox
- `git ls-remote origin HEAD` สำหรับ repository โครงการยังสำเร็จ

ค่าที่บันทึกกับสถานะเครือข่ายของเครื่องที่กำลังรันเป็นคนละหลักฐาน จึงไม่สรุปว่าโดเมนขาดหรือผู้ใช้ยังไม่ได้บันทึก และไม่ขอเพิ่มรายการเดิมซ้ำ ไม่มีการ bypass proxy หรือปิดการตรวจใบรับรอง

## สิ่งที่ยังต้องแก้

ต้องให้ runtime อนุญาตคำขอเหล่านี้ผ่าน proxy จริง เช่น ลองเริ่มงานจากเวอร์ชันสภาพแวดล้อมล่าสุดและทดสอบอีกครั้ง หากยังถูกปฏิเสธ ให้ผู้ดูแลแพลตฟอร์มตรวจการบังคับใช้ egress policy โดยใช้ผล CONNECT 403 ข้างต้น การเริ่มงานใหม่เป็นแนวทางวินิจฉัย ไม่ใช่สิ่งที่ยืนยันแล้วว่าจะหาย

ยังไม่มีเครื่องมือในแชตนี้สำหรับสั่ง refresh/publish runtime หรือตรวจ live egress policy โดยตรง จึงไม่อ้างว่าซ่อมเครือข่ายแล้ว

สามารถใช้เอกสารมาตรฐานที่มีสิทธิ์ใช้งานและมีข้อมูลระบุฉบับ/ที่มาครบมาพัฒนาต่อได้ โดยไม่ต้องรอเว็บไซต์ ส่วน RCTankC ยังต้องมีคู่ผลตัวอย่างหากต้องการเทียบกับต้นแบบ
