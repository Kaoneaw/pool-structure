# สิ่งที่ยังไม่ทราบและต้องยืนยัน

ผู้ใช้อนุญาตให้ค้นจากมาตรฐานและงานของผู้อื่น (20 ตุลาคม 2026) จึงไม่จำเป็นต้องมีคู่มือต้นแบบเพื่อพัฒนาวิธีใหม่ แต่ยังต้องมีหลักฐานสมการและข้อกำหนดฉบับที่ใช้จริงก่อนเปิดผลตรวจทางวิศวกรรม

1. มาตรฐานไทยฉบับล่าสุด พร้อมวันที่มีผลบังคับใช้ พื้นที่และประเภทอาคารที่ครอบคลุม — แหล่งทางการยังถูกเครือข่ายปฏิเสธ
2. ข้อกำหนด ACI 318/350 ที่ใช้ร่วมกัน รวม load factors, strength reduction, environmental durability factor, minimum reinforcement และ crack/leakage control พร้อมเลขข้อ/หน้า — ยังไม่มีฉบับเต็มให้ตรวจ
3. การรองรับผนังและพื้น: cantilever, propped, two-way, soil springs หรือกรอบ/แผ่น และรอยต่อระหว่างผนัง–พื้น–ขอบ — ไม่อนุมานว่าขอบยึดแน่นโดยอัตโนมัติ
4. น้ำใต้ดินวัดจาก datum ใด, ดินอิ่มน้ำ/ไม่อิ่มน้ำ, หน่วยน้ำหนักจม, K₀/Ka/Kp, surcharge และระบบระบายน้ำ — ช่องข้อมูลในแอปไม่ใช่คำยืนยันแบบจำลองแรงดัน
5. กรณีสระเต็ม/ว่าง/ก่อสร้าง/ทดสอบน้ำ: แรงภายนอกที่เกิดร่วมกัน ทิศแรง เกณฑ์ load combination และน้ำหนักที่อนุญาตให้นับต้าน uplift
6. เกณฑ์ flotation FS, bearing และ settlement: ต้องยืนยันรายงานดิน โมเดลการยุบตัว และเกณฑ์ของโครงการ ไม่มีการใช้ค่า FS หรือ modulus ดินที่เดาเอง
7. พื้นที่แผ่นดินไหว ชั้นดิน ความสำคัญ โครงสร้างรองรับ และ liquid impulsive/convective effects — ไม่ใช้ PGA ที่ใส่ลอย ๆ เป็นผลตรวจ
8. เหล็กเสริมต้องมีจำนวนหน้า/ชั้น ทิศทาง เหล็กขอบ เหล็กทาบ พัฒนาแรง งอ และสูญเสีย ก่อนรวมเป็นน้ำหนักเหล็ก ไม่ใช้การประมาณจากระยะห่างอย่างเดียว
9. คู่ข้อมูลเข้า → ผล RCTankC ที่มีหน่วยและรุ่นโปรแกรม สำหรับ regression และโหมดเทียบต้นแบบ — ไม่สามารถสรุปจาก `.exe`
10. รูปทรงอื่น เช่น สระโค้ง พื้นขั้น บันได ช่องเปิด รอยต่อ และขอบที่อยู่บนผนัง ต้องระบุเพิ่มเติม ปัจจุบันรองรับสี่เหลี่ยม พื้นลาดเชิงเส้น และขอบวงแหวนด้านนอกเท่านั้น

## การปลดบล็อก

ตรวจซ้ำแล้วค่าที่บันทึกมีโดเมนครบและไม่มี draft ค้าง แต่ runtime ยังตอบ CONNECT 403 แม้ทดสอบนอก shell sandbox จึงไม่ขอเพิ่มโดเมนเดิมซ้ำ ดู [ผลวินิจฉัยเครือข่าย](network-diagnosis.md) สำหรับหลักฐานและการตรวจต่อ หากมีเอกสารที่ได้รับสิทธิ์ใช้งานอยู่แล้ว สามารถนำมาใช้อ้างอิงได้โดยไม่ต้องรอเว็บไซต์

ระหว่างรอ แอปเปิดใช้ดูแบบและถอดปริมาณรูปทรง แต่ไม่แสดงผ่าน/ไม่ผ่านทางโครงสร้าง
