# เปรียบเทียบต้นแบบกับมาตรฐานปัจจุบัน

| รายการ | RCTankC | มาตรฐานปัจจุบัน | พฤติกรรมแอป |
|---|---|---|---|
| สมมติฐานการรองรับ | ไม่มีเอกสาร | ต้องเลือกตามโครงสร้างจริง | ไม่คำนวณ M/V |
| Load factors / combinations | ไม่ทราบ | รอฉบับและเลขข้อยืนยัน | ไม่ใส่ค่าเดา |
| กำลังวัสดุ / φ | ไม่ทราบ | รอข้อกำหนดและเกรดวัสดุ | ผู้ใช้เก็บข้อมูลได้ แต่ยังไม่ตรวจ |
| Durability / environmental factors | ไม่ทราบ | รอ ACI 350 ที่ตรวจได้ | ไม่สรุปผ่าน |
| เหล็กขั้นต่ำและรอยร้าว | ไม่ทราบ | รอเกณฑ์และสมมติฐาน | ไม่แสดงค่ารอยร้าวที่ไม่มีฐาน |
| แผ่นดินไหว | ไม่ทราบ | รอ มยผ. พื้นที่และชั้นดิน | รอข้อมูล |
| Uplift FS / bearing / settlement | ไม่ทราบ | รอเกณฑ์และรายงานดิน | ไม่คำนวณค่าความปลอดภัย |
| หน่วยและโจทย์ตัวอย่าง | ไม่มีผลอ้างอิง | ไม่เกี่ยวกับฉบับมาตรฐานโดยตรง | ยังไม่รายงาน % ความต่าง |

ไม่ได้ยืนยันว่าต้นแบบใช้มาตรฐานเก่าหรือว่าค่าแตกต่างกัน ตารางนี้เป็นทะเบียนสิ่งที่ต้องตรวจ ไม่ใช่ผลวิเคราะห์ความต่างที่เสร็จแล้ว ตัวเลือกต้นแบบใน UI ปิดไว้พร้อมเหตุผลจนกว่าจะมีข้อมูลอ้างอิงที่ตรวจได้
