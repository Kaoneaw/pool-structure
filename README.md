# Pool Studio · เครื่องมือวางแผนโครงสร้างสระ

เว็บ static ภาษาไทย ใช้ three.js, web-ifc และ pdf.js ไม่มี backend ไฟล์ PDF/IFC ประมวลผลในเบราว์เซอร์ ไม่ส่งออกไปยังบริการภายนอก ฟอนต์และ WASM รวมไว้ใน build

> ผลลัพธ์เป็นการประเมินเบื้องต้นเพื่อช่วยออกแบบ ไม่ใช่การคำนวณออกแบบสำหรับยื่นขออนุญาต ต้องให้วิศวกรโยธาที่มีใบอนุญาตตรวจสอบและรับรองก่อนใช้งานจริง

## เริ่มใช้งาน

ต้องใช้ Node.js 22.13+ (แนะนำ Node 24) และ npm

```sh
npm ci
npm run dev
```

หาก home directory เขียนไม่ได้ใน cloud ให้ใช้ `export NPM_CONFIG_CACHE=/workspace/.npm-cache` ก่อน `npm ci`

```sh
npm test
npm run build
npm run preview
```

ไฟล์พร้อมเผยแพร่อยู่ใน `dist/` ต้องเสิร์ฟผ่าน HTTP/HTTPS ไม่เปิด `index.html` ด้วย `file://` ซอร์สมี build step แต่เว็บที่สร้างแล้วเป็น static ล้วน ไม่มีเซิร์ฟเวอร์ประมวลผลแอป

## สิ่งที่ใช้ได้

- สระสี่เหลี่ยมพื้นลาดตามยาว ตัวอย่าง 5 × 10 ม. ลึก 1.2–1.8 ม. โมเดลสด มุมมองบน/หน้า/ข้าง/ไอโซ โปร่งใส หน้าตัด วัดระยะ และแยกสีตามชนิด
- PDF ลากวาง/เลือกไฟล์ เปลี่ยนหน้า ซูม เลื่อน ตั้งสเกลจาก 2 จุดแยกแต่ละหน้า วัดระยะ และวางหน้า PDF ใน 3D พร้อมตำแหน่ง/หมุน/โปร่งใส การเปลี่ยนหน้าหรือไฟล์ซ่อนแผ่นเดิม
- IFC เปิดใน Web Worker มี progress/ยกเลิก แผนผังตามชนิด/พื้นที่ ซ่อนตามชนิด อ่าน Properties/Pset/Qto/วัสดุ เลือกค่าที่ตรวจหน่วยแล้วไปใส่ฟอร์ม ไม่นำขนาด bounding box มาแทนขนาดภายในสระ
- คอนกรีต พื้นที่แบบหล่อผนังสองด้าน ผิวกันซึม/กระเบื้องเต็มภายใน และปริมาตรน้ำตามระดับ พร้อมสูตรในหน้าจอและรายงาน
- CSV, รายงานผ่านหน้าพิมพ์ → บันทึกเป็น PDF, IFC4 จากโมเดลพารามิเตอร์ (IfcWall/IfcSlab, hierarchy, วัสดุ, Pset/Qto)
- localStorage เฉพาะพารามิเตอร์และธีม สำรอง/กู้คืน JSON ไม่เก็บไฟล์ PDF/IFC ถาวร

การเปลี่ยนค่าฟอร์มต้องกด **อัปเดตโมเดลและปริมาณ** ก่อนบันทึก/ส่งออก เพื่อให้ตัวเลขและโมเดลตรงกัน ปุ่มส่งออกเตือนหากมีค่าค้างไม่อัปเดต

## ขอบเขตที่ยังไม่เสร็จ

**ยังไม่ใช่โปรแกรมออกแบบโครงสร้างที่ตรวจผ่านมาตรฐาน** เว็บไซต์มาตรฐานไทย/ACI ถูก proxy ปฏิเสธ และไม่มีเอกสารสมการ/คู่ผลต้นแบบ จึงไม่เดา load factor, วิธีวิเคราะห์, รอยร้าว หรือเกณฑ์ผ่าน

ยังไม่คำนวณแรงดัน M/V กำลังดัด/เฉือน เหล็กขั้นต่ำ รอยร้าว uplift FS bearing/settlement แผ่นดินไหว และน้ำหนักเหล็ก ปุ่มเทียบ RCTankC แจ้งข้อมูลที่ขาด ไม่มีการรันหรือแกะไฟล์ `.exe`

อ่าน [การวิเคราะห์อ้างอิง](docs/reference-analysis.md), [สถานะมาตรฐาน](docs/standards.md), [ตารางความต่างที่รอตรวจ](docs/standards-diff.md), [คำถามที่ต้องยืนยัน](docs/open-questions.md) และ [ผลทดสอบ](docs/test-report.md)

## ข้อจำกัดรูปทรงและ IFC

- ความหนาพื้นวัดแนวดิ่ง ผนังตั้งตรง ผิวบนอยู่ที่ datum เดียวกัน พื้นลาดตามแนวยาวและต่อแนวลาดถึงผิวนอก ขอบวงแหวนอยู่ด้านนอกผนัง ไม่รวมช่องเปิด บันได รอยต่อ และสูญเสีย
- พื้นที่กันซึมเป็นผิวภายในเต็มสระ ไม่ใช่เฉพาะพื้นที่เปียก แบบหล่อคิดเฉพาะผนัง ไม่รวมพื้นและขอบ
- น้ำในฟอร์มวัดจากพื้นด้านลึก น้ำใต้ดินเก็บเป็นข้อมูลไว้ ยังไม่ใช้วิเคราะห์แรง
- IFC สูงสุด 200 MB เพื่อจำกัดความเสี่ยงหน่วยความจำ ยังไม่ได้ benchmark ไฟล์ขนาดใหญ่จริง รองรับ geometry ตามที่ web-ifc อ่านได้
- IFC ที่เปิดอาจย้าย origin ใกล้ศูนย์สำหรับการแสดงผล ไม่ใช่ georeferencing ระหว่าง PDF กับ IFC ต้องปรับตำแหน่งเอง
- IFC ส่งออกจากโมเดลสระที่กำหนด ไม่ใช่การแก้ไข/ส่งออก IFC ที่อัปโหลด ไม่รวมไฟล์ PDF เป็น IFC
- การทดสอบ round-trip IFC4 ไม่ใช่ buildingSMART certification
- ไม่รองรับ PDF เข้ารหัส ต้องใช้ไฟล์ที่ปลดล็อกแล้ว

## GitHub Pages

มี workflow `.github/workflows/pages.yml` สำหรับ build/test และ deploy หลัง push สู่ `main` ตั้งค่า repository → Settings → Pages → Source เป็น **GitHub Actions** ก่อนใช้งาน `base: './'` รองรับ path ใต้ชื่อ repository ตรวจผลการเผยแพร่ที่แท็บ Actions และใช้ URL ที่ GitHub แสดงหลัง deploy สำเร็จ

## ดาวน์โหลดเป็นแพ็ก static

```sh
# ต้องมี Python 3 เฉพาะขั้นตอนแพ็กไฟล์
npm run package:static
python3 scripts/package-static.py --verify
```

ได้ `artifacts/pool-studio-static.zip` พร้อม checksum, ฟอนต์, workers, WASM, licenses และคู่มือใช้งาน ไม่ต้องติดตั้ง Node/npm ที่ hosting และไม่มี `.exe` อยู่ในแพ็ก ต้องเสิร์ฟไฟล์ทั้งหมดผ่าน HTTP/HTTPS ไม่เปิดด้วย `file://`

การสร้างแพ็กไม่เผยแพร่เว็บไซต์ ดู `วิธีใช้งาน.txt` ในแพ็กสำหรับ GitHub Pages แบบ branch หรือใช้ workflow GitHub Actions กับ source repository ตามข้างต้น

## ทดสอบเบราว์เซอร์

```sh
npm run build
npm run test:browser
# หรือระบุไฟล์ Chromium ในระบบอื่น
CHROMIUM_PATH=/path/to/chromium npm run test:browser
```

ไม่มีการใช้ `.exe` ใน test ใด ๆ โจทย์ unit tests เป็นเรขาคณิตคำนวณมือ ไม่ใช่ผล RCTankC
